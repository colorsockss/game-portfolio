# 게임 개발 포트폴리오

클라이언트, 서버, 개발 툴을 처음부터 만든 게임 포트폴리오입니다. 게임 두 개와 두 게임이 함께 쓰는 데이터·공식 툴이 한 저장소에 있습니다.

| 프로젝트 | 한 줄 소개 | 기술 | 상태 |
| --- | --- | --- | --- |
| [키우기 (idle)](idle/README.md) | 방치형 RPG. 클라이언트가 예측하고 서버가 같은 규칙으로 확정 | Unity 6, PuerTS(TypeScript), Node, SQLite | 개발 중, Android·Live 서버 배포 |
| [MMORPG (mmo)](mmo/README.md) | 틱 기반 상태 서버 하나에 Unity와 Unreal 클라이언트가 붙는 MMO | C#(.NET) 서버, Unity(C#), Unreal(C++) | 준비 중 |
| [데이터 툴](tools/data-tool/README.md) | Excel → MessagePack 데이터와 타입 있는 로더, 테이블 간 참조 검사 | Node | 두 게임이 함께 씀 |
| [공식 툴](tools/formula-tool/README.md) | 게임 공식 편집, 코드 생성, 전투 미리보기 데스크톱 앱 | Tauri, SvelteKit | 두 게임이 함께 씀 |

## AI 네이티브 개발

**이 저장소에서 작성하고 제작한 코드, 아트, 사운드는 모두 AI가 만들었습니다.** 사람은 제품 방향, 아키텍처 의사결정, 품질 기준과 최종 검수를 맡고, 구현과 에셋 제작은 AI 에이전트가 수행하는 AI 네이티브 워크플로로 개발했습니다.

| 영역 | 만든 방법 |
| --- | --- |
| 코드 | AI 코딩 에이전트(Claude Code)가 클라이언트, 서버, 공용 게임 규칙, 개발 툴, 테스트, CI/CD를 작성 |
| 캐릭터·몬스터 | Codex image_gen으로 생성하고, AI가 짠 후처리 파이프라인이 고정 팔레트로 평탄화하고 프레임 크기를 맞춤. 영웅·몬스터·보스·소환수 12종, 216프레임 |
| UI | AI가 짠 그리기 스크립트로 UI 테마 13장을 만들고, AI가 벡터로 그린 아이콘 원본 28개를 256×256 PNG로 구워 사용 |
| 배경 | Codex image_gen으로 스테이지마다 장면을 그린 뒤 원경과 근경 두 겹으로 편집하고, AI가 짠 후처리가 좌우 끝을 이어 붙임. 6개 스테이지, 12겹. 전투 중 근경은 걸은 만큼, 원경은 그 절반만큼 흘러 패럴랙스 |
| 사운드 | AI가 짠 신시사이저가 사각파·삼각파·잡음으로 BGM 3곡과 효과음 11개를 합성. 외부 음원 없이, 같은 시드면 같은 파일 |

AI가 만든 결과물은 저장소 규칙(`AGENTS.md`)과 자동 검사(타입 검사, 생성 파일 검사, import 경계 검사, 테스트)로 지킵니다. 외부에서 가져온 것은 엔진·라이브러리(Unity, PuerTS, npm 패키지 등)와 글꼴(SIL OFL)뿐이고, 에셋 스토어 그림이나 음원은 쓰지 않았습니다.

## 구조

```
idle/                키우기
  client/            Unity 프로젝트 (게임 로직은 TypeScript/, C#은 엔진 브리지만)
  server/            게임 서버
  shared/            클라이언트와 서버가 반드시 같은 코드를 써야 하는 것
  integration/       클라이언트와 서버를 함께 돌리는 테스트
  balance/           밸런스 시뮬레이션
  data/              기획 데이터 원본
  docs/              백로그, 성능, 릴리스, 설계 기록
mmo/                 MMORPG (준비 중)
tools/
  data-tool/         Excel → 데이터와 타입 있는 로더, 테이블 간 검사
  formula-tool/      공식 편집, 코드 생성, 전투 미리보기 (데스크톱 앱)
scripts/             생성 파일 갱신·검사, import 경계 검사
```
