# @idle/big-number

큰 수 `Big = { m, e }`(m × 10^e, 1 ≤ |m| < 10)입니다.

- 일반 객체로 유지합니다(클래스 금지). 연산은 `Big.add(a, b)` 같은 함수입니다.
- 사칙연산·비교와 10^0–10^22만 씁니다. `Math.pow`·`Math.log10`은 쓰지 않고, 거듭제곱은 정수 지수만 받습니다.
- 수량은 `Big.floor`로 맞추고, int64 테이블 값은 `Big.from`으로 바꿉니다.
- 테이블의 `big` 열(십진 문자열)은 `Big.parse`로 바꿉니다. 지수부를 따로 읽으므로 double을 넘는 값도 받습니다.
- 표기(1.2K)는 클라이언트 `presentation/format/big.ts`가 맡습니다.
- 연산을 바꾸면 경계값(0, 음수, 큰 지수 차이, 10^22 초과) 테스트를 넣습니다.
