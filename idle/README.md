# 키우기 (idle)

영웅 하나가 몬스터 웨이브를 자동으로 사냥하고, 플레이어는 장비·스킬·강화·환생으로 성장시키는 방치형 RPG입니다. 클라이언트(Unity + PuerTS)와 서버(Node)가 같은 TypeScript 게임 규칙을 써서, 클라이언트는 입력을 바로 화면에 반영하고 서버는 같은 코드로 결과를 확정합니다.

## 한눈에 보기

| | |
| --- | --- |
| 클라이언트 | Unity 6000.6.0f1, PuerTS Core/V8 3.0.3. 게임 로직은 모두 TypeScript, C#은 엔진 브리지(파일, UI, 전투 월드, WebSocket, 오디오, 번들 받기)만 |
| 서버 | Node 22, WebSocket + MessagePack, SQLite(`node:sqlite`) |
| 공용 | TypeScript 패키지 다섯 개: 패킷·오류 번호(`codes`), 통신 계약(`protocol`), 게임 규칙(`game-core`), 큰 수(`big-number`), 테이블(`data-schema`) |
| 데이터 | Excel 테이블 14개 → MessagePack과 타입 있는 로더, 공식 17개 → 생성 코드 |
| 배포 | Android APK, 원격 패치(코드·데이터·에셋), 게임 서버와 패치 파일은 VPS, GitHub Actions로 단위별 내보내기와 되돌리기 |
| 범위 밖 | 결제, 광고, 외부 SDK. 로그인은 텍스트 ID |

## 게임 기능

- **전투**: 여러 마리가 함께 나오는 웨이브, 보스 도전과 시간 제한, 스킬(범위 공격, 사용 조건), 버프·디버프, 발사체, 소환수, 부활
- **성장**: 레벨, 골드로 하는 능력치 강화, 장비(착용, 강화, 같은 장비 합성), 스킬(배우기, 장착, 레벨업), 환생(영구 배율)
- **오프라인 보상**: 접속하지 않은 시간(최대 12시간)만큼 다음 접속의 첫 정산이 지급
- **그 밖**: 스테이지 해금, 튜토리얼, 한국어·영어, BGM·효과음, 설정, 디버그 오버레이와 개발 서버 치트

## 기술 포인트

### 규칙 한 벌로 예측과 확정

게임 규칙은 `shared/game-core`에 `(상태, 커맨드, 시각) → 새 상태`인 순수 함수로 한 벌만 있습니다. 클라이언트는 커맨드를 보내면서 같은 규칙으로 결과를 미리 적용하고, 서버는 같은 코드로 검증해 저장한 뒤 바뀐 상태 대신 결과의 지문(키를 정렬한 JSON의 53비트 해시)만 돌려줍니다. 클라이언트는 자기 예측의 지문과 견주어 같으면 그대로 확정하고, 다를 때만 저장 데이터를 다시 받습니다. 그래서 응답이 평균 75바이트이고, 서버는 그대로 권위라 조작한 클라이언트가 지문을 무시해도 저장 데이터는 바뀌지 않습니다.

규칙은 시계를 읽지 않고 시각을 인자로 받으므로 오프라인 보상과 일일 리셋도 단위 테스트로 검증합니다. 커맨드에 새 opcode를 더하고 핸들러를 빠뜨리면 타입 검사가 실패합니다.

### 조작할 수 없는 전투, 비트까지 같은 결과

클라이언트는 전투를 화면에 보여 줄 뿐 결과를 보내지 않습니다. 서버는 저장된 체크포인트와 자기 시각만으로 같은 시뮬레이션(100 ms 틱)을 다시 돌려 보상을 확정합니다. 이것이 되려면 PuerTS V8과 Node의 계산이 마지막 비트까지 같아야 해서, 큰 수 `Big`(`{ m, e }`, m × 10^e)은 엔진마다 결과가 다를 수 있는 `Math.pow`·`Math.log10`을 쓰지 않고 사칙연산과 정확히 표현되는 10의 거듭제곱만 씁니다. 공식의 거듭제곱도 정수 지수의 곱셈으로 생성됩니다. 전투 테스트는 결정성, 골든 벡터, 모든 틱에서 다시 시작해도 같은 결과인지를 확인합니다.

### 동시성과 데이터 무결성

- 저장은 읽었던 revision에서만 넘어갑니다(`UPDATE … WHERE revision = ?`). 다른 요청이 먼저 저장했으면 그 데이터 위에서 커맨드를 다시 적용합니다.
- 커맨드의 답은 저장과 같은 트랜잭션에 요청 id로 기록됩니다. 연결이 끊겨 같은 id로 다시 보내면 다시 실행하지 않고 처음 답을 돌려줍니다.
- 계정당 연결은 하나이고, 세션 토큰은 해시만 저장합니다. 재연결 전후 두 연결이 동시에 보낸 커맨드, 한 번만 지급, 부분 쓰기, 저장 형식 마이그레이션을 서버 테스트가 재현합니다.

### 측정한 성능과 서버 비용

실제 WebSocket 클라이언트 수천 개로 배포 번들 서버에 부하를 걸어 쟀습니다(Apple M4 Max, Node 22.14, 2026-10-22).

| 동접 | 초당 요청 | p50 | p99 | CPU(코어 하나) | RSS |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1,000 | 100 | 1.06 ms | 3.49 ms | 10.9% | 116 MiB |
| 10,000 | 1,000 | 0.48 ms | 10.57 ms | 38.5% | 191 MiB |
| 15,000 | 1,500 | 0.54 ms | 12.76 ms | 49.0% | 247 MiB |

- 비용의 대부분은 전투 계산이 아니라 저장과 통신입니다. 접속한 1시간의 전투 계산은 약 10.5 ms입니다.
- 초당 커밋 2,000부터 SQLite WAL 체크포인트가 꼬리 지연을 만들어, CPU보다 먼저 한계가 됩니다.
- 코어 하나에 동접 약 20,000명(M4 Max), 클라우드 vCPU(AWS Graviton3)는 단일 스레드 성능과 디스크 fsync를 반영해 약 5,000명으로 잡았습니다. 지문 확정으로 응답을 줄인 뒤 **동접 1,000명에 월 약 $9**(계산과 트래픽)입니다.

### 원격 패치

앱에는 패치를 마칠 때까지 필요한 부트 번들(약 50 KB)만 들고, 게임 코드, 데이터, Addressables 카탈로그와 에셋은 패치로 받습니다.

- 받은 번들은 두 슬롯에 번갈아 설치하고 설치된 슬롯 이름을 임시 파일 + 교체로 바꿔, 어디서 꺼져도 반쯤 받은 번들로 시작하지 않습니다.
- 모든 파일을 크기와 SHA-256으로 검증하고, 바뀌지 않은 파일은 설치된 번들에서 복사합니다.
- 번들이 부르는 C# API의 지문을 매니페스트에 넣어, C#이 바뀐 앱에 맞지 않는 번들은 받지 않습니다.
- 서버는 연결할 때 프로토콜 버전과 규칙 테이블의 지문을 확인해, 데이터만 바꾼 배포에도 옛 규칙으로 예측하는 클라이언트를 남기지 않습니다.

### 데이터와 공식 파이프라인

기획 데이터(xlsx)는 [데이터 툴](../tools/data-tool/README.md)이, 공식은 [공식 툴](../tools/formula-tool/README.md)이 타입 있는 TypeScript 코드로 바꿉니다. 테이블 간 참조, 값 범위, Enum, 조건부 열 같은 규칙은 코드가 아니라 스키마 시트의 열에 두고, 위반은 `파일: 시트!셀 (열): 내용`으로 모아 알립니다. 시트에 없는 상수 이름을 쓰는 코드는 타입 검사가 실패하고, 생성 파일이 원본과 다르면 테스트가 실패합니다. 밸런스 시뮬레이션은 서버가 만드는 새 계정으로 N시간을 같은 규칙으로 플레이해 성장 곡선을 CSV로 냅니다.

### 클라이언트 구조

`domain` → `application` → `adapters`·`presentation` → `unity` 순서의 층으로 나누고, 안쪽 층은 Unity를 모릅니다. 화면은 MVVM입니다. 뷰모델은 신호(`@preact/signals-core`)로 보일 값을 내고 Node에서 테스트하며, 뷰는 바인딩 표 하나로 프리팹의 컴포넌트와 이어집니다. 프리팹은 에디터 코드로 만들고 다시 빌드해도 fileID가 그대로라, 바뀐 프리팹만 diff에 나옵니다. 층 사이 import는 `npm test`가 검사합니다.

## 테스트와 배포

워크스페이스마다 vitest로 테스트하고, `integration/`은 클라이언트 앱을 서버 로직에 붙여 예측과 확정이 같은지, 끊김과 잃은 답, 다른 곳 로그인을 확인합니다. 와이어는 대표 요청·응답 33개의 MessagePack 바이트를 스냅숏으로 고정합니다. 화면 연출, 프리팹, C#은 Unity에서 확인합니다.

PR과 `main` 푸시마다 GitHub Actions가 타입 검사와 전체 테스트(생성 파일·import 경계 검사 포함)를 돌립니다. Live(VPS)에는 패치(코드, 규칙 테이블, 문장·소리, 에셋), 게임 서버, APK를 단위별 액션으로 내보내고 되돌리며, 고르지 않은 단위는 지금 Live 버전에서 가져오고 서버나 앱과 맞지 않는 조합은 내보내기 전에 멈춥니다.
