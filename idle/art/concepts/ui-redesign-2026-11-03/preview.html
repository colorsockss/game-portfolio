슬레이어 키우기에서 가져올 UX

지금문제개편
강화·스킬·장비·가방·환생이 화면을 덮는 팝업방치형의 핵심인 "전투를 보면서 키우기"가 안 됨. 열고 닫는 데 탭 두 번아래 탭 + 아래 판. 판은 화면 아래 40%에만 열리고 전투는 늘 보임. 고른 탭을 다시 누르면 판이 접혀 전투가 커짐
스테이지 이름과 "0/3" 글자만얼마나 남았는지, 보스가 언제인지 안 보임위쪽 스테이지 막대: 웨이브 점 → 보스 해골, 다 차면 "보스 도전" 버튼이 막대 옆에서 깜빡임. 스테이지 이름을 누르면 스테이지 목록
영웅 HP는 머리 위 작은 막대뿐지금 강한지 약한지 판단할 근거가 없음전투 아래 능력치 띠: HP 막대, 공격, 치명. 강화하면 띠의 수치가 바로 오르며 반짝임
장착 스킬이 전투 중에 안 보임스킬을 배우고 장착한 효과를 체감할 수 없음스킬 바: 장착한 스킬 세 칸과 재사용 대기 시계
강화는 한 번 누르면 한 단계골드가 쌓이면 수십 번 눌러야 함×1·×10·×100 배수, 길게 누르면 연속 강화, "지금 → 다음" 수치, 못 사는 줄은 회색 버튼
장비는 글자 목록과 별도 강화·합성 판무엇이 좋은지 한눈에 안 보임등급 색 칸 그리드, 강화 수치·합성 개수 막대·착용 표시, "일괄 장착"·"일괄 합성"
스킬은 글자 목록스킬을 구분할 수 없음속성 색 아이콘 칸, 잠긴 스킬은 자물쇠, 고른 스킬의 설명과 레벨업·장착

그림체 규칙(첨부 이미지 기준)

요소규칙
외곽선모든 버튼·칸·패널·아이콘에 짙은 남보라(#2B2236) 외곽선. 기준 화면에서 7~8px
버튼채도 높은 단색 + 위 광택 + 아래 턱(같은 색의 어두운 단). 초록 = 사기/진행, 노랑 = 강조(보스, 합성), 빨강 = 위험(환생), 파랑 = 장착, 회색 = 비활성
패널크림색 판 + 갈색 글자, 제목은 주황 꼬리표. 위쪽 HUD와 아래 탭은 짙은 남색, 능력치 띠는 나무색
등급일반 회색 → 고급 초록 → 희귀 파랑 → 영웅 보라 → 전설 주황. 칸의 아래 42%를 어둡게
글자둥글고 굵은 한글 글꼴(시안은 OFL인 Jua) + 외곽선과 아래 그림자. 수치는 흰색, 강조는 노랑·초록
아이콘·배경배우(용사·몬스터)와 같은 평면 색면 + 외곽선. 지금 아이콘은 사실적인 그림이라 배우와 어긋남. 배경은 지금 24픽셀 도트라 배우와 어긋남
