# MMORPG (mmo)

**준비 중입니다.** 키우기([idle](../idle/README.md))를 마무리한 뒤에 시작하며, 아직 코드는 없습니다.

틱마다 이동과 전투를 계산해 주변 플레이어에게 보내는 상태 서버 하나에 Unity와 Unreal 클라이언트가 함께 붙는 MMORPG를 만듭니다. 두 클라이언트는 같은 패킷 스키마에서 생성한 코드를 받아 같은 조건으로 서버에 붙습니다.

## 계획

| 부분 | 기술 |
| --- | --- |
| 서버 | C#(.NET). 틱 루프, 시야(AOI), 이동 검증, 저장 |
| Unity 클라이언트 | C#만, UI Toolkit |
| Unreal 클라이언트 | C++, UMG |
| 통신 | TCP 위의 길이 접두사 바이너리 패킷. 언어 중립 스키마에서 C#·C++ 코드 생성 |
| 데이터 | 저장소 루트의 [데이터 툴](../tools/data-tool/README.md)과 [공식 툴](../tools/formula-tool/README.md)에 C#·C++ 출력을 더해 사용 |
